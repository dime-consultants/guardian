🎯 HOW IT WORKS

DEMO MODE (No Backend Required):
  1. User uploads file (CSV, TXT, XLSX, PDF, DOCX, JSON)
  2. File stored in memory with blob URL
  3. User requests processing ("Convert to Excel", "Analyze data", etc.)
  4. Request sent to Grok AI with file context
  5. Grok returns response + PROCESSED_DATA_JSON
  6. Frontend extracts and displays processed data
  7. User clicks "Download XLSX File" button
  8. Browser downloads converted file

BACKEND MODE:
  1. Same upload and request flow
  2. Request sent to Django backend instead of Grok
  3. Backend processes and returns formatted data
  4. Frontend displays and allows download
  5. No files permanently stored

🔌 BACKEND INTEGRATION

When implementing the Django backend, use these endpoints (from BACKEND_API.md):

1. POST /api/chat/message/
   - Send chat message with optional files
   - Returns processed response

2. POST /api/chat/process-file/
   - Process and convert uploaded files
   - Returns structured data

3. POST /api/chat/convert-format/
   - Convert between file formats
   - Returns formatted file content

4. POST /api/chat/export-data/
   - Export data in specified format
   - Returns downloadable file

See docs/BACKEND_API.md for full specifications.
